## Findings

### R02-1. `prpstn:hall-a.63`'s self-adjointness half has no `\lean{}` tag
- severity: minor
- category: uses-tags
- location: `blueprint/src/sections/sec10/spectral-theorems.tex:1107-1112` (statement) and
  `:1109` (`\lean{}` tag); paired with `Physicslib4/Spectral/Forms.lean:732-751` and `:777-781`
- protected: no
- verdict: confirmed
- evidence: The blueprint states two conclusions in one proposition: "If $Q$ is a bounded
  quadratic form ... there is a unique $A$ ... such that $Q(\psi) = \langle \psi, A\psi\rangle$
  ... If $Q(\psi)$ belongs to $\mathbb{R}$ for all $\psi$, then the operator $A$ is self-adjoint."
  The node's only `\lean{}` entry is
  `\lean{Physicslib4.Spectral.existsUnique_operator_of_isBoundedQuadraticForm}`, and that Lean
  theorem's conclusion is only `∃! A : H →L[ℂ] H, ∀ ψ : H, Q ψ = ⟪ψ, A ψ⟫_ℂ` — it says nothing
  about self-adjointness. The self-adjointness half is formalized as a separate declaration,
  `IsBoundedQuadraticForm.isSelfAdjoint_toOperator` (`Forms.lean:777`), but a search of
  `spectral-theorems.tex` for `isSelfAdjoint_toOperator` returns no occurrences: it is cited from
  no blueprint node at all. The node is marked `\leanok`, so a reader trusting that mark would
  believe the whole two-part statement is tied to Lean code, when only half of it is actually
  referenced.
- proposed fix: add `Physicslib4.Spectral.IsBoundedQuadraticForm.isSelfAdjoint_toOperator` to the
  `\lean{}` list of `prpstn:hall-a.63`.

### R02-2. `nolint unusedArguments` on `Physicslib4.Spectral.L0` is justified but outside blueprint scope
- severity: nit
- category: lean-style
- location: `Physicslib4/Spectral/BorelClasses.lean:279-282`
- protected: no
- verdict: confirmed
- evidence: `@[nolint unusedArguments] def L0 (X : Type*) [TopologicalSpace X] [MeasurableSpace X] : Set (Set X) := ...`.
  The preceding docstring explains the attribute: "The blueprint also asks that `E` be
  measurable. That is not recorded here: under `[BorelSpace X]` an indicator which is a
  pointwise limit of continuous functions is automatically measurable ... carrying the conjunct
  would make every membership proof discharge a derivable obligation." This is a justified,
  commented `nolint`, not a lint-gate workaround. Noted only because `def:L0-class`
  (`spectral-theorems.tex:4003`) falls outside this review's blueprint line range (1-3006), so the
  blueprint-side half of this comparison was not checked by this review.
- proposed fix: none; flagging for whichever review covers `spectral-theorems.tex` lines
  3990-4320 to confirm the blueprint text at `def:L0-class` itself documents the dropped
  measurability conjunct (it does, per a quick check: "under this measurability convention..." —
  not independently verified in depth here).

### R02-3. Informal contraction "it's" in a proof
- severity: nit
- category: prose
- location: `blueprint/src/sections/sec10/spectral-theorems.tex:242`
- protected: no
- verdict: confirmed
- evidence: "In the case $\|\psi\| = 0$ the sequence $\{A_i\psi\}_{i \in \mathbb{N}}$ consists
  only of zeros. Hence, it's trivially a Cauchy sequence." The rest of the section consistently
  avoids contractions ("it is", "does not").
- proposed fix: "Hence, it is trivially a Cauchy sequence."

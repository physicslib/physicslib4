## Findings

### R10-1. `IsGroundStateForFlow`'s GNS witness is pinned to `Type`, not `Type u`
- severity: minor
- category: definition-correctness
- location: `Physicslib4/AQFT/HaagKastler/QuasilocalKMS.lean:96-105` (vs. the sibling pattern at
  `Physicslib4/AQFT/HaagKastler/QuasilocalIntertwiner.lean:550-563`)
- protected: yes (it is a `def`, a design decision per CLAUDE.md)
- verdict: confirmed
- evidence: `QuasilocalKMS.lean` opens with `variable (N : HaagKastlerNet)` (no `.{u}` annotation,
  line 44) and then
  ```
  def IsGroundStateForFlow (flow : ℝ → InhomogeneousLorentzGroup)
      (ω : Physicslib4.GNS.State N.quasilocal.carrier) : Prop :=
    (∀ (t : ℝ) (a : N.quasilocal.carrier), ...) ∧
      ∃ (K : Type) (_ : NormedAddCommGroup K) (_ : InnerProductSpace ℂ K) ...
  ```
  (`K : Type`, i.e. `Type 0`). Contrast the sibling theorem in the same chapter,
  `IsInvariantState.exists_gns_unitary (N : HaagKastlerNet.{u})`, whose witness is
  `∃ (H : Type u) ...` — explicitly tracking the net's own universe. `HaagKastlerNet` itself is
  declared with `universe u` precisely so that local/quasilocal algebras need not live in a fixed
  universe (see the docstring at `Net.lean:60-66`: "universe polymorphic... pinned algebras in one
  fixed universe" is explicitly what the polymorphism is there to avoid). `IsGroundStateForFlow`
  reintroduces exactly that pinning for its GNS witness.
- proposed fix: state `IsGroundStateForFlow` with `N : HaagKastlerNet.{u}` and
  `∃ (K : Type u) ...`, matching `IsInvariantState.exists_gns_unitary` and the rest of the GNS
  existence lemmas in the same file/chapter. (Flagging only, per the auditor's remit — not making
  the change.)

### R10-2. Blueprint under-reports the strength of `IsInvariantState`'s GNS-unitary results
- severity: nit
- category: blueprint-lean-mismatch
- location: blueprint `haag-kastler-axioms.tex:1883-1895` (`thrm:invariant-state-gns-unitary`) vs.
  `Physicslib4/AQFT/HaagKastler/QuasilocalIntertwiner.lean:550-645`
- protected: no
- verdict: confirmed
- evidence: the blueprint node's `\lean{}` tag names only
  `HaagKastlerNet.IsInvariantState.exists_gns_unitary`. The Lean file additionally proves, right
  next to it, `exists_gns_unitary_strongContinuous` (strong continuity under a weak-continuity
  hypothesis on matrix coefficients), `exists_gns_unitaryRep` (bundled as a `MonoidHom` into
  `H ≃ₗᵢ[ℂ] H`), and `exists_gns_unitaryRep_strongContinuous`. None of these three is cited by any
  blueprint node in scope. This is not an error — the extra lemmas are strictly stronger/more
  convenient forms of the same mathematical fact — but the blueprint's account of what has been
  formalized here is incomplete.
- proposed fix: add a remark (or additional `\lean{}` names on `thrm:invariant-state-gns-unitary`,
  or a short new blueprint item) covering the bundled/strongly-continuous variants, so the
  blueprint's description of `QuasilocalIntertwiner.lean` is complete.

### R10-3. Minor wording: "unconditionally for β > 0" in the KMS module docstring
- severity: nit
- category: prose
- location: `Physicslib4/AQFT/KMS.lean:38-39`
- protected: no
- verdict: confirmed
- evidence: "KMS states are automatically `α`-invariant (`IsKMSState.invariant`, unconditionally
  for `β > 0` by `IsKMSState.invariant_of_pos`)." `invariant_of_pos` does take `hβ : 0 < β` as a
  hypothesis, so "unconditionally" is potentially misread as "with no hypotheses at all"; it means
  "without the separate `StripLiouville β` hypothesis that `IsKMSState.invariant` needs."
- proposed fix: reword to, e.g., "...and `IsKMSState.invariant_of_pos` discharges that extra
  hypothesis automatically whenever `β > 0`."
